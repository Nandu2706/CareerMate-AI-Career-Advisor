
# 🚀 CareerMate - AI Career Advisor

CareerMate is an AI-powered career guidance assistant
built using Python, Google Gemini, Tavily and Gradio.

## Features
- Personalized career recommendations
- Live web search for job trends
- Salary information
- Learning roadmaps
- Interview preparation
- Conversation memory

## Technologies
- Python
- Google Gemini API
- Tavily Search API
- Gradio

## Installation

pip install -r requirements.txt

## Run

python main.py

## Environment Variables

GEMINI_API_KEY=your_api_key
TAVILY_API_KEY=your_api_key
